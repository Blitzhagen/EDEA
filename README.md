# Elite Dangerous Exploration Assistent (EDEA)

EDEA is an open-source, MIT-licensed companion app for Elite Dangerous.

## Goal

Provide a feature-rich exploration companion for Elite Dangerous with a clean, maintainable, privacy-first codebase and new assets.


## Technology

- .NET 8
- WPF
- SQLite (Dapper)
- CommunityToolkit.Mvvm
- log4net
- MIT License
